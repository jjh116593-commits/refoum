치료실 업무 흐름 개선안

요청한 기능의 동작 흐름을 시험 데이터로 확인하는 독립 미리보기입니다.

주의: 이 화면은 실제 운영 앱·환자 데이터·Supabase에 연결되어 있지 않습니다. 버튼은 이 데모 안에서만 동작합니다. 운영 적용용 패키지는 별도이며 실제 설치·배포는 테스트 환경에서 검증해야 합니다.

01 · 장비 대기열 / 점검 상태

장비를 반환한 뒤 사용 가능으로 전환합니다. 점검 중인 장비는 환자 베드에 배치하지 않습니다.

저주파 01 · 대기공간사용 가능

02 · 이전 방문 치료내역 비교

직전 방문 기록과 오늘 기록을 비교해 추가·제외·변경을 분리합니다.

저주파 · 10분 → 15분변경
온열 · 오늘 기록에 없음제외
운동교육 · 새로 기록추가
비교 대상은 현황판에 기록된 치료 항목이며 별도 처방 원본과 다를 수 있습니다.

03 · 직원별 주의사항

주의사항을 등록하고 확인 이력을 화면에서 구분합니다.

04 · 복합 치료 순서 / 장소 준비

치료 단계를 순서대로 표시하고 다음 장소 준비 상태를 확인합니다.

1. 온열 치료 · 온열 베드완료
2. 저주파 · 저주파 구역진행 중
3. 운동교육 · 운동 공간대기

05 · 로컬 호출 프로그램 사용 시 웹 팝업 억제

전용 호출 프로그램이 실행 중일 때 사용자가 웹 팝업을 숨기도록 설정합니다.

웹 호출 팝업이 표시됩니다.

브라우저는 임의의 로컬 프로세스를 직접 탐지할 수 없습니다. 실제 앱에서는 이 PC의 설정을 사용하며, 자동 감지는 네이티브 브리지 연동이 필요합니다.

06 · 일일 메모 확인 후 퇴실

일일 메모가 있을 때 메모 확인 단계를 거쳐 퇴실합니다.
